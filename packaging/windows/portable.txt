PDF portable mode

While this file sits next to iridium-pdf.exe, PDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the PdfCraftData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move PDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\PDF and
%LOCALAPPDATA%\PDF) instead. If PdfCraftData can't be written (for example on a read-only
drive), PDF says so and uses the per-user folders instead.

Opening PDF files with this copy

The portable copy doesn't register itself with Windows, so picking it under "Open with" may not
stick. To offer it in Settings > Apps > Default apps, open PowerShell in this folder and run:

  $exe = (Resolve-Path .\iridium-pdf.exe).Path
  $c = "HKCU:\Software\Classes"
  $cap = "HKCU:\Software\PDF.Portable\Capabilities"
  foreach ($k in "$c\PDF.Portable\shell\open\command", "$c\.pdf\OpenWithProgids",
                 "$cap\FileAssociations", "HKCU:\Software\RegisteredApplications") {
    if (!(Test-Path $k)) { New-Item -Path $k -Force | Out-Null }
  }
  Set-Item -Path "$c\PDF.Portable" -Value "PDF Document"
  Set-Item -Path "$c\PDF.Portable\shell\open\command" -Value "`"$exe`" `"%1`""
  New-ItemProperty -Path "$c\.pdf\OpenWithProgids" -Name PDF.Portable -Value "" -PropertyType String -Force | Out-Null
  New-ItemProperty -Path $cap -Name ApplicationName -Value "PDF (portable)" -PropertyType String -Force | Out-Null
  New-ItemProperty -Path $cap -Name ApplicationDescription -Value "Open-source PDF workbench" -PropertyType String -Force | Out-Null
  New-ItemProperty -Path "$cap\FileAssociations" -Name .pdf -Value PDF.Portable -PropertyType String -Force | Out-Null
  New-ItemProperty -Path "HKCU:\Software\RegisteredApplications" -Name "PDF (portable)" -Value "Software\PDF.Portable\Capabilities" -PropertyType String -Force | Out-Null

Then open Settings > Apps > Default apps, search for .pdf (or for PDF) and choose it. This
changes only your own user's settings (HKEY_CURRENT_USER), and it doesn't change the default app by
itself. If you move or rename this folder, run it again from the new place.

To undo, first choose another app for .pdf in Settings > Apps > Default apps (otherwise Windows
keeps pointing PDF files at the removed entry), then run:

  Remove-Item -Path "HKCU:\Software\Classes\PDF.Portable", "HKCU:\Software\PDF.Portable" -Recurse -ErrorAction SilentlyContinue
  Remove-ItemProperty -Path "HKCU:\Software\Classes\.pdf\OpenWithProgids" -Name PDF.Portable -ErrorAction SilentlyContinue
  Remove-ItemProperty -Path "HKCU:\Software\RegisteredApplications" -Name "PDF (portable)" -ErrorAction SilentlyContinue
  foreach ($k in "HKCU:\Software\Classes\.pdf\OpenWithProgids", "HKCU:\Software\Classes\.pdf") {
    $i = Get-Item -Path $k -ErrorAction SilentlyContinue
    if ($i -and $i.ValueCount -eq 0 -and $i.SubKeyCount -eq 0) { Remove-Item -Path $k }
  }

The last lines delete the .pdf keys only when nothing else is left in them, so another app's entry
there stays.
